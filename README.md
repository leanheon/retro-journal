# 내맘대로 살거야 · 김지헌

바랜 신문지 색, 먹색 활자, 빈티지 타자기 선화와 이중 괘선을 사용한 개인 블로그입니다.

한글 제목과 굵은 글씨에는 첨부한 KBL 폰트를, 본문과 일반적인 글씨에는 Paperlogy 폰트를 사용합니다. 메인 타자기는 제공한 이미지의 바깥 배경을 정리해 사용했고, 소개와 글 끝에는 제공한 서명을 배치했습니다. 읽기 화면은 PC에서 2단, 모바일에서 1단 지면입니다.

## 지금 보기

현재 PC에서 `블로그-실행.cmd`를 실행한 뒤 다음 주소를 여세요.

- 블로그: http://127.0.0.1:5173/
- 글 관리: http://127.0.0.1:5173/admin

실행 창을 닫으면 로컬 사이트가 종료됩니다. 관리자 화면은 설정한 비밀번호로 로그인합니다. 이 서버는 127.0.0.1에서만 실행하며 인터넷 서비스용으로 사용하지 않습니다.

## 글 쓰기

1. 관리자 화면에서 비밀번호를 입력하고 ‘편집실 들어가기’를 누릅니다.
2. ‘새 글 쓰기’에서 제목·요약·본문·글 주소를 입력합니다. 글 주소에는 영문과 한글을 사용할 수 있습니다.
3. 일상·생각·취향·만들기 중 분류를 고릅니다. 태그는 쉼표로 구분합니다.
4. 본문 서식 도구에서 제목·굵게·기울임·인용·목록·코드·링크·가로줄을 넣습니다. Ctrl/Cmd+B·I·K·F로 강조·링크·검색을 사용할 수 있고, 실행 취소·다시 실행과 글자 수·읽는 시간도 제공합니다. 기존 마크다운 글은 그대로 편집합니다.
5. ‘사진 추가 · 편집’으로 8MB 이하 PNG·JPEG·WebP·GIF 이미지를 고릅니다. 본문에 사진을 붙여넣거나 끌어놓아도 편집기가 열립니다. 자르기 비율·확대·회전·좌우/상하 반전·밝기·대비·흑백을 조절한 뒤 ‘편집한 이미지 넣기’를 누르세요. ‘원본 그대로 넣기’는 편집 없이 넣습니다. 새 사진의 설명은 대체 텍스트로 저장됩니다.
6. ‘사진 보관함’에서 이미 올린 사진을 넣거나 편집하고, ‘본문 사진 편집’에서 사용 중인 사진을 다시 다듬습니다. 편집본은 새 파일로 저장되어 원본을 보존합니다. 같은 사진이 이 글에 여러 번 쓰였으면 함께 교체되며 설명은 유지됩니다. 같은 사진을 표지로 쓰고 있다면 표지도 함께 바뀝니다.
7. ‘표지 선택’에서 ‘올린 사진에서 고르기’로 기존 사진을 선택하거나 ‘표지 사진 올리기’로 새 사진을 올립니다. ‘표지 사진 편집’으로 표지만 다듬을 수도 있습니다. 표지만 올리거나 편집하면 본문에는 사진이 삽입되지 않습니다.
8. ‘사진 표현’에서 ‘신문 흑백’ 또는 ‘원본 컬러’를 선택합니다. ‘표지 위에 제목 표시’는 글마다 켜고 끌 수 있습니다.
9. ‘미리보기’ 또는 ‘넓게 미리보기’에서 표지·본문·서명을 확인하고 ‘임시 저장’ 또는 ‘공개 저장’을 누릅니다. 쓰기·미리보기 전환 시 편집 내용과 되돌리기 기록을 유지합니다. 사진 편집 결과도 글을 저장해야 반영됩니다.

이미지 편집본은 긴 변 4,096px·8MB 이내로 저장합니다. GIF를 편집하면 한 장의 이미지로 저장되며, 움직임을 유지하려면 ‘원본 그대로 넣기’를 선택하세요. PNG 투명도를 보존합니다.

편집기는 [CodeMirror 6 / React CodeMirror](https://github.com/uiwjs/react-codemirror), 이미지 자르기는 [react-easy-crop](https://github.com/ValentinH/react-easy-crop)을 사용합니다. 두 프로젝트의 MIT 라이선스 고지는 설치 패키지에 포함됩니다.

공개 저장한 글은 방문자가 읽을 수 있습니다. 초안으로 바꾸면 글과 초안에서만 참조한 사진은 방문자에게 숨겨집니다. 발행 전에 내려받은 자료까지 회수되는 것은 아닙니다. ‘추천 글로 표시’를 선택하면 홈 첫 글로 표시됩니다. 삭제는 확인 후 실행됩니다.

이메일 구독과 뉴스레터 발송 기능은 제거했습니다. RSS는 `/feed.xml`에서 이용할 수 있습니다.

## 관리자 비밀번호

로그인은 8시간 유지되며 ‘로그아웃’을 누르면 해당 세션을 즉시 폐기합니다. 로그인은 비밀번호 하나로 확인합니다. IP·접속 주소·Origin·Referer·Sec-Fetch-Site는 로그인이나 관리 권한을 판단하는 조건으로 사용하지 않습니다. 비밀번호를 바꾸면 다른 기기의 기존 로그인은 무효화되고, 현재 브라우저는 새 세션으로 계속 사용할 수 있습니다.

‘마이페이지’에서 현재 비밀번호를 확인한 뒤 새 비밀번호를 정할 수 있습니다. 첫 실행에는 서버에 준비된 기본 비밀번호로 들어간 다음, 같은 화면에서 개인 비밀번호로 바꾸세요. 새 비밀번호는 8~256자의 인쇄 가능한 문자로 설정합니다.

비밀번호 원문은 소스·백업에 포함하지 않습니다. 변경한 비밀번호 해시는 서버의 D1에 보관합니다. 최초 초기화에 `BLOG_ADMIN_PASSWORD_HASH` 환경 설정이 있으면 사용하고, 없으면 서버에 준비된 기본 비밀번호 해시를 사용합니다. 데이터베이스에 비밀번호가 만들어진 뒤 환경 설정을 바꿔도 기존 비밀번호는 덮어쓰지 않습니다. 소스 ZIP에는 변경한 개인 비밀번호 해시와 세션 데이터가 포함되지 않습니다.

비밀번호를 잊어버린 경우 로컬에서 `node scripts/set-admin-password.mjs`를 실행해 새 비밀번호를 두 번 입력하세요. 입력 내용과 해시는 화면에 표시되지 않으며, D1에 바로 저장되므로 개발 서버를 재시작할 필요가 없습니다. 공개 서버는 로그인된 상태에서 마이페이지에서 변경하고, 로그인할 수 없는 경우에는 해당 서버의 D1 복구 절차를 사용합니다.

## 본문 서식

```markdown
## 작은 제목

문단과 **굵은 글씨**, *기울임*, `인라인 코드`

- 목록 하나
- 목록 둘

> 인용문

[링크 이름](https://example.com)

![사진 설명](/media/업로드한-사진-주소.png)
```

사진 아래 설명이 필요하면 다음 문단에 씁니다. HTML 코드는 실행하지 않고 문자로 표시합니다.

## 소개와 백업

‘소개와 설정’에서 블로그 이름, 작성자 이름, 설명, 소개글을 바꿀 수 있습니다.

‘백업 다운로드’는 글·초안·설정을 JSON으로 저장합니다. **사진 원본 파일은 JSON에 포함되지 않습니다.** 업로드된 사진은 별도 서버 저장소(R2)에 유지됩니다. 사진 원본도 개인적으로 보관해 주세요.

‘백업 합치기’는 새로운 글 주소만 추가하고 기존 주소의 글은 유지합니다. 블로그 설정은 백업 파일의 설정으로 변경됩니다. 복원 전에 현재 백업을 내려받는 것을 권장합니다.

## 공개 배포 상태

Sites 프로젝트와 공개 읽기 권한, 관리자 계정, 저장소 연결 설정을 준비했습니다. 현재 공개 배포는 미완료입니다.

2026-10-10 재확인에서도 Sites 저장소 호스트 `git.chatgpt-team.site`가 이 PC의 DNS에서 `0.0.0.0` / `::`으로 조회되어 소스 연결이 막혀 있습니다. DNS·네트워크 설정을 임의로 변경하지 않았습니다. 저장소 연결이 정상화되면 같은 프로젝트 ID로 소스 동기화와 배포를 재개해야 합니다. 새 사이트를 다시 만들 필요는 없습니다.

예약된 주소(아직 서비스 중이 아님): https://yeobaek-journal-epogo.sok78ksu94.chatgpt.site

## 개발과 검증

- 런타임: Node.js 22.13 이상
- UI: React / Vinext
- 글과 설정: Cloudflare D1
- 사진: Cloudflare R2
- 관리자 인증: 서버의 PBKDF2 비밀번호 확인 + D1 세션, HttpOnly 쿠키
- `/feed.xml`, `/sitemap.xml`, `/robots.txt` 지원
- `.dev.vars`, `.wrangler`, `.sites-runtime`, `node_modules`는 소스 배포에서 제외

```text
node scripts/run-framework.mjs dev
node node_modules/typescript/bin/tsc --noEmit
node scripts/run-framework.mjs build
node tests/integration.mjs
node tests/cover-integration.mjs
node tests/password-auth-integration.mjs
node tests/password-change-integration.mjs
node tests/password-session-state.mjs
node tests/login-origin-integration.mjs
```

통합 테스트는 기본적으로 127.0.0.1:5173의 로컬 데이터베이스에서 실행됩니다. 다른 로컬 포트는 `BLOG_TEST_ORIGIN`으로 지정하고, 두 접속 주소의 로그인 테스트는 `BLOG_TEST_PORT`로 포트를 지정합니다. 테스트용 글을 작성하고 종료 시 삭제합니다. 실제 배포 데이터와는 별개입니다.

인증 테스트와 글·표지 통합 테스트는 실행 환경의 `BLOG_TEST_PASSWORD`가 필요합니다. 비밀번호를 소스나 테스트 파일에 적지 마세요. 비밀번호 변경 통합 테스트는 임시 비밀번호를 사용한 뒤 원래 테스트 비밀번호로 복원합니다.

검증 항목: 작성·수정·삭제, 한글 주소, 초안 비공개, 비밀번호 인증, 요청 주소 정보에 관계없는 로그인·로그아웃·관리 요청, 사진 형식·업로드·비공개, HTML 이스케이프, RSS·사이트맵, 백업·기존 글 보존 복원, 표지 설정 저장·복원, 기존 업로드 목록, 본문 없이 표지로만 참조한 사진의 공개 범위, 1MB를 넘는 실제 사진 업로드. 화면은 320px·390px 모바일과 1280px 데스크톱에서 확인했습니다.
