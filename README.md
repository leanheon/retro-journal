# 여백 기록실 · 김지헌

크림색 종이, 굵은 활자, 벽돌색·녹색 띠를 사용한 개인 블로그입니다.

## 지금 보기

현재 PC에서 `블로그-실행.cmd`를 실행한 뒤 다음 주소를 여세요.

- 블로그: http://127.0.0.1:5173/
- 글 관리: http://127.0.0.1:5173/admin

실행 창을 닫으면 로컬 사이트가 종료됩니다. 로컬 미리보기의 ChatGPT 로그인은 개발용 계정 모의 로그인입니다. 이 서버는 127.0.0.1에서만 실행하며 인터넷 서비스용으로 사용하지 않습니다.

## 글 쓰기

1. 관리자 화면의 ‘ChatGPT로 로그인’을 누릅니다. 공개 배포 후에는 이 사이트를 만든 ChatGPT 계정으로 로그인해야 합니다.
2. ‘새 글 쓰기’에서 제목·요약·본문·글 주소를 입력합니다. 글 주소에는 영문과 한글을 사용할 수 있습니다.
3. 일상·생각·취향·만들기 중 분류를 고릅니다. 태그는 쉼표로 구분합니다.
4. ‘사진 넣기’로 8MB 이하 PNG·JPEG·WebP·GIF 이미지를 올립니다. 본문에 사진 주소가 자동 삽입됩니다.
5. ‘미리보기’에서 확인하고 ‘임시 저장’ 또는 ‘공개 저장’을 누릅니다.

공개 저장한 글은 방문자가 읽을 수 있습니다. 초안으로 바꾸면 글과 초안에서만 참조한 사진은 방문자에게 숨겨집니다. 발행 전에 내려받은 자료까지 회수되는 것은 아닙니다. ‘추천 글로 표시’를 선택하면 홈 첫 글로 표시됩니다. 삭제는 확인 후 실행됩니다.

## 본문 서식

```markdown
## 작은 제목

문단과 **굵은 글씨**, *기울임*, `인라인 코드`

- 목록 하나
- 목록 둘

> 인용문

[링크 이름](https://example.com)

![사진 설명](/media/업로드한-사진-주소.png)
```

사진 아래 설명이 필요하면 다음 문단에 씁니다. HTML 코드는 실행하지 않고 문자로 표시합니다.

## 소개와 백업

‘소개와 설정’에서 블로그 이름, 작성자 이름, 설명, 소개글을 바꿀 수 있습니다.

‘백업 다운로드’는 글·초안·설정을 JSON으로 저장합니다. **사진 원본 파일은 JSON에 포함되지 않습니다.** 업로드된 사진은 별도 서버 저장소(R2)에 유지됩니다. 사진 원본도 개인적으로 보관해 주세요.

‘백업 합치기’는 새로운 글 주소만 추가하고 기존 주소의 글은 유지합니다. 블로그 설정은 백업 파일의 설정으로 변경됩니다. 복원 전에 현재 백업을 내려받는 것을 권장합니다.

## 공개 배포 상태

Sites 프로젝트와 공개 읽기 권한, 관리자 계정, 저장소 연결 설정을 준비했습니다. 현재 공개 배포는 미완료입니다.

2026-10-09 배포 시도에서 Sites 저장소 호스트 `git.chatgpt-team.site`가 이 PC의 DNS에서 `0.0.0.0` / `::`으로 조회되어 Git 연결이 실패했습니다. DNS·네트워크 설정을 임의로 변경하지 않았습니다. 저장소 연결이 정상화되면 같은 프로젝트 ID로 소스 동기화와 배포를 재개해야 합니다. 새 사이트를 다시 만들 필요는 없습니다.

예약된 주소(아직 서비스 중이 아님): https://yeobaek-journal-epogo.sok78ksu94.chatgpt.site

## 개발과 검증

- 런타임: Node.js 22.13 이상
- UI: React / Vinext
- 글과 설정: Cloudflare D1
- 사진: Cloudflare R2
- 관리자 인증: Sites의 ChatGPT 인증 + 서버의 소유자 이메일 검사
- `/feed.xml`, `/sitemap.xml`, `/robots.txt` 지원
- `.dev.vars`, `.wrangler`, `.sites-runtime`, `node_modules`는 소스 배포에서 제외

```text
node scripts/run-framework.mjs dev
node node_modules/typescript/bin/tsc --noEmit
node scripts/run-framework.mjs build
node tests/integration.mjs
```

통합 테스트는 127.0.0.1:5173의 개발 데이터베이스에서만 실행됩니다. 테스트용 글을 작성하고 종료 시 삭제합니다. 실제 배포 데이터와는 별개입니다.

검증 항목: 작성·수정·삭제, 한글 주소, 초안 비공개, 소유자 인증, 교차 출처 쓰기 거부, 사진 형식·업로드·비공개, HTML 이스케이프, RSS·사이트맵, 백업·기존 글 보존 복원. 화면은 390px 모바일과 데스크톱에서 확인했습니다.
